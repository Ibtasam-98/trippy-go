# TrippyGo

A Flutter project for travel and booking.

## Overview

TrippyGo is a mobile application built with Flutter, designed to facilitate travel planning and booking. It offers distinct functionalities for administrators and regular users.

**Administrator Features:**

* **User Management:**
    * Add new users to the system.
    * View existing user profiles and details.
    * Delete user accounts.
* **Accommodation Management:**
    * Add new accommodation listings (e.g., hotels, hostels, apartments).
    * View details of existing accommodations.
    * Delete accommodation listings.

**User Features:**

* **Booking Management:**
    * Add new bookings for accommodations.
    * View their existing booking details.
    * Delete or cancel bookings.
* **Search Functionality:**
    * Search for accommodations based on various criteria (e.g., location, dates, price).
* **Reviews and Ratings:**
    * Submit reviews and ratings for accommodations they have stayed in.
    * View reviews and ratings submitted by other users.
